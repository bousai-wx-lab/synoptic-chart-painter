# 専門天気図カラーノート

気象庁のアジア500hPa・300hPa高度・気温・風・等風速線天気図（AUPQ35）1枚に、トラフ・強風軸の推定候補をボタンで重ねる静的ツールです。手描きでも補足できます。2026年10月2日00UTCの1枚だけを対象とする解析試作版です。

## 操作

- 「標準の解析案を表示」で下段500hPaのトラフ候補を茶の二重線、上段300hPaの強風軸候補を緑の線で表示します。個別に表示を切り替えられ、繰り返しても線は増えません。「原図だけ」は解析案だけを外します。
- ＋・−で25〜400%まで拡大・縮小でき、「全体に戻す」で1枚を収めます。拡大時は図をドラッグして移動します。倍率は閲覧枠の幅が基準です。
- 「手描きで補足する」を開くと、以下の手描き道具が使えます。

- 色・太さ・濃さを選び、図をドラッグして着色します。黒い原図は常に残ります。
- 消しゴムは着色だけを消します。取り消し・やり直しは1筆単位です。
- 表示を拡大し、移動モードで図をドラッグできます。全体を選ぶと1枚に戻ります。
- PNG保存は原図・表示中の解析案・手描き・出典・推定の制限をまとめて端末へ保存します。
- 手描きの全消去には確認があり、取り消しで戻せます。解析案は独立した層です。
- 着色はメモリ内だけで保持します。再読み込みやタブを閉じると消えるので必要な画像を保存してください。100%以上の表示は閲覧枠の幅を基準にした拡大率です。

## 解析案の計算と制限

風速・風向を読んだ気象解析ではなく、等高度線だけから候補を作る幾何的な試作です。強風軸の確定、最大風速や流れの向きの判断には使えません。気象庁の解析や予報ではありません。

原図PDFから連続した高度線を抽出し、海岸線・数値の字形・矢羽根・破線を除外した33本をcontours.jsonへ収録しています。このPDFの線の太さと形を確認して抽出したもので、任意のPDFや別の日時へ無検証で適用できる抽出器ではありません。曲線は原画像の画素座標です。source・imageのSHA-256、観測時刻、2048×2993の寸法がchart.jsonと一致しない場合は解析案を出しません。元の黒い図は変更しません。

図の経線の交点を円弧状の緯線の中心として使い、曲線を角度と中心からの距離へ変換します。緯線自体の湾曲をトラフと取り違えないための変換で、緯度・経度や実距離を数値出力するものではありません。

- 500hPaトラフ候補：閉曲線と角度幅0.48rad以下の短い線を除き、0.012radごとに南側の交点を標本化します。左右約0.096radより7画素以上南へ張り出す点を抽出します。同じ線の近接ピークの二重採用を避け、角度差0.18rad・距離差210画素以内の点を、異なる3本以上の曲線かつ90画素以上の南北幅がある場合だけ結びます。閉じた低気圧中心や短波のトラフを網羅しません。
- 300hPa強風軸候補：0.018radごとに5本以上の高度線がある場所を調べます。4本の連続する線の平均間隔が10〜90画素、周囲の間隔の中央値の80%未満となる帯で、中央2本の中間を結びます。8標本未満の線、70画素を超えて飛ぶ部分はつなぎません。緑の淡い幅は見やすさのための28画素で、一定風速以上の範囲ではありません。等風速線や矢羽根とは未照合です。

角度を調べる範囲は−1.05〜0.5radです。抽出不足・密集や曲がりが不明瞭な場所は候補を出しません。候補がないことはトラフや強風がない証明ではありません。解析資料が欠けた場合は原図の閲覧・手描き・拡大縮小を残し、解析ボタンを停止します。計算の検証は合成した円弧・谷・密集帯と、この1枚への重ね合わせに限定しており、他日・他図の気象解析精度は未検証です。

## 図と出典

原図：[気象庁 AUPQ35 00UTC PDF](https://www.jma.go.jp/bosai/numericmap/data/nwpmap/aupq35_00.pdf)。初版は2026年10月2日00UTC（09:00 JST）の図を取得し、全ページを縦横比を保った2048×2993 PNGへ画像化しています。上段は300hPa、下段は500hPaです。取得した1枚を表示し、自動更新は行いません。原図URLの内容は後日更新されるため、画面の図の日時を確認してください。

利用条件：[気象庁ホームページの利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html)（公共データ利用規約第1.0版）。出典・画像化を画面に表示し、利用者による着色を気象庁の解析として扱いません。原図の気象要素の値は変更しません。取得PDFは公開リポジトリに含めず、レビューした画像と抽出線だけを配信します。図のハッシュ・寸法・取得日時はchart.jsonと公開許可一覧に固定しています。

解析案と手描きは図を読み取る補助です。PCのPDFを開く機能、自動更新、過去分の保存はまだありません。最新の状況は気象庁の原資料で確認してください。

## 開発・公開

`python3 -m http.server 8765 --bind 127.0.0.1` でローカル表示できます。ブラウザ側に依存ライブラリ・第三者CDN・解析タグはありません。

公開するファイルはrelease-allowlist.jsonの完全一致一覧で管理します。変更後は`python3 -B scripts/update_manifest.py`、`node scripts/test_analysis.js`、`python3 -B scripts/privacy_gate.py`、`python3 -B scripts/test_privacy_gate.py`、`python3 -B scripts/test_pages_release.py`を実行してください。Gitの投稿者は許可した公開用の名前とGitHub非公開用メールだけを使います。画像を更新するときは原図の日時、権利、目視確認、メタデータ除去、許可する画像ハッシュを再確認してください。

mainとrelease用ブランチで全Git objectを検査し、検査後の同一commitから許可ファイルだけを梱包します。Pages配備はmainだけです。配備される画像・コードはローカルと同じバイトです。公開時刻や通信ログと利用者の着色内容は別です。詳細はSECURITY.mdを参照してください。
