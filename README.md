# 専門天気図カラーノート

気象庁のアジア500hPa・300hPa高度・気温・風・等風速線天気図（AUPQ35）1枚に、利用者が半透明の色を重ねて読み込む静的ツールです。初版は手動着色です。自動解析・自動着色・予報の生成は行いません。

## 操作

- 色・太さ・濃さを選び、図をドラッグして着色します。黒い原図は常に残ります。
- 消しゴムは着色だけを消します。取り消し・やり直しは1筆単位です。
- 表示を拡大し、移動モードで図をドラッグできます。全体を選ぶと1枚に戻ります。
- PNG保存は原図・着色・出典をまとめて端末へ保存します。
- 全消去には確認があり、取り消しで戻せます。
- 着色はメモリ内だけで保持します。再読み込みやタブを閉じると消えるので必要な画像を保存してください。100%以上の表示は閲覧枠の幅を基準にした拡大率です。

## 図と出典

原図：[気象庁 AUPQ35 00UTC PDF](https://www.jma.go.jp/bosai/numericmap/data/nwpmap/aupq35_00.pdf)。初版は2026年10月2日00UTC（09:00 JST）の図を取得し、全ページを縦横比を保った2048×2993 PNGへ画像化しています。上段は300hPa、下段は500hPaです。取得した1枚を表示し、自動更新は行いません。原図URLの内容は後日更新されるため、画面の図の日時を確認してください。

利用条件：[気象庁ホームページの利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html)（公共データ利用規約第1.0版）。出典・画像化を画面に表示し、利用者による着色を気象庁の解析として扱いません。原図の気象要素の値は変更しません。取得PDFは公開リポジトリに含めず、レビューした画像だけを配信します。図のハッシュ・寸法・取得日時はchart.jsonと公開許可一覧に固定しています。

着色は寒気・強風帯などを利用者が読み取る補助です。自動的な危険度判定は行いません。最新の状況は気象庁の原資料で確認してください。

## 開発・公開

`python3 -m http.server 8765 --bind 127.0.0.1` でローカル表示できます。依存ライブラリ・第三者CDN・解析タグはありません。

公開するファイルはrelease-allowlist.jsonの完全一致一覧で管理します。変更後は`python3 -B scripts/update_manifest.py`、`python3 -B scripts/privacy_gate.py`、`python3 -B scripts/test_privacy_gate.py`、`python3 -B scripts/test_pages_release.py`を実行してください。Gitの投稿者は許可した公開用の名前とGitHub非公開用メールだけを使います。画像を更新するときは原図の日時、権利、目視確認、メタデータ除去、許可する画像ハッシュを再確認してください。

mainとrelease用ブランチで全Git objectを検査し、検査後の同一commitから許可ファイルだけを梱包します。Pages配備はmainだけです。配備される画像・コードはローカルと同じバイトです。公開時刻や通信ログと利用者の着色内容は別です。詳細はSECURITY.mdを参照してください。
