# 天気図解析マスター

Weather Chart Analysis Master

[ツールを開く](https://bousai-wx-lab.github.io/weather-chart-analysis-master/)

気象庁のアジア500hPa・300hPa高度・気温・風・等風速線天気図（AUPQ35）1枚に、風速帯の緑色の塗り分けと、トラフ・強風軸の推定候補をボタンで重ねる静的ツールです。手描きでも補足できます。2026年10月2日00UTCの1枚だけを対象とする解析試作版です。

## 操作

- 「風速を色塗り」で上段300hPaを等風速線に沿って緑色で塗り分けます。同じボタンでもう一度押すと外せます。40〜60、60〜80、80〜100、100〜120、120kt以上の5段階で、風速が強いほど濃い緑です。区分は下限を含み、上限を含みません。40kt未満と下段500hPaは着色しません。
- 「標準の解析案を表示」で下段500hPaのトラフ候補を茶の二重線、上段300hPaの強風軸候補3本を滑らかな赤い矢印で表示します。個別に表示を切り替えられ、繰り返しても線は増えません。「原図だけ」は風速の色塗りと解析案を外します。
- ＋・−で25〜400%まで拡大・縮小でき、「全体に戻す」で1枚を収めます。拡大時は図をドラッグして移動します。倍率は閲覧枠の幅が基準です。
- 「手描きで補足する」を開くと、以下の手描き道具が使えます。

- 色・太さ・濃さを選び、図をドラッグして着色します。黒い原図は常に残ります。
- 消しゴムは着色だけを消します。取り消し・やり直しは1筆単位です。
- 表示を拡大し、移動モードで図をドラッグできます。全体を選ぶと1枚に戻ります。
- PNG保存は原図・表示中の解析案・手描き・出典・推定の制限をまとめて端末へ保存します。
- 手描きの全消去には確認があり、取り消しで戻せます。解析案は独立した層です。
- 着色はメモリ内だけで保持します。再読み込みやタブを閉じると消えるので必要な画像を保存してください。100%以上の表示は閲覧枠の幅を基準にした拡大率です。

原図のL・H・C・Wは、初期表示で文字部分だけを色分けします。Lは赤、Hは青、Cは水色、Wはオレンジです。「文字の色分けを外す」で黒い文字に戻り、「原図だけ」は風速・解析案と文字の色分けを外します。手描きは独立です。PNGには表示中の文字色と色の凡例を含めます。

文字は同じ原図PDFの線から取り出した固定データ（center-symbols.json）を使い、元画像にある文字の画素だけを選んで通常合成で色を置き換えます。選択には描画時の輪郭差を吸収する1画素の幅を加えますが、白い画素には描きません。元の位置と見えている文字の形を保ち、背景の四角や塗り潰しは描きません。原図画像は変更しません。原図・画像のSHA-256、観測時刻、寸法と気圧面が一致しない場合は文字の色分けを停止し、黒い原図は残します。任意のPDFからの文字検出は未実装です。

## 陸海の塗り方を比較

操作パネルの「陸と海」で、細かなドット、大きなドット、斜線、逆向きの斜線、クロスハッチ、横線、陸は点・海は波、紙の質感、砂と水面、衛星写真の10案を切り替えます。初期表示は細かなドット・濃さ40%です。濃さは0〜100%で調整でき、陸海だけを外すこともできます。「原図だけ」は陸海・文字色・風速・解析案を外します。手描きは独立です。選んだ塗り方と濃さはPNGにも反映します。

海岸線は同じ原図PDFの線から抽出した固定データ（land-sea.json）です。短い切れ目をつなぎ、図の端に達する大陸は枠に沿って閉じています。77個の閉じた輪郭を偶奇規則で塗り、湖などの内水面は海側と同じ表現にします。上段300hPaと下段500hPaは同じ地理を使用します。黒い原図を残す乗算合成で、風速・解析案・文字色より下に重ねます。任意の図や別日時の海岸線の自動抽出は未実装です。原図・画像・日時・寸法が合わない資料は表示を停止します。

衛星写真案は[NASA Blue Marble Next Generation](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-map/)の2004年10月の地表画像です（NASA Earth Observatory / Reto Stoeckli）。現在の航空写真・雲画像ではありません。元の5400×2700画像を、原図の経緯線から合わせた極心平射図法へ投影変換し、画像を薄く重ねます。原図の緯線との位置合わせ誤差は0.46画素以内で、NASA画像自体の海岸線の解像度・原図との細部の違いは残ります。[NASAの画像利用案内](https://science.nasa.gov/earth/faq/)に基づき、出典と年月を画面・PNGに記載します。画像は同じサイトから配信し、画像のハッシュ・寸法が違う場合は衛星写真案だけを停止します。

## 解析案の計算と制限

風速の色塗りは、原図に印刷された20kt間隔の等風速線（破線）とその数値を、この1枚について確認した領域です。PDFの破線の各点を元画像の画素座標へ変換し、破線や数値表示の切れ目を直線でつないで境界を復元しています。図の端に達する線は同じ端に沿って閉じます。弱風の穴や離れた強風域も保持します。領域はwind-bands.jsonに収録し、原図・画像のSHA-256、観測時刻、画像寸法、300hPa、ktの単位と区分を照合してから表示します。

この色塗りは格子風速の補間や新しい強風軸の解析ではありません。境界と値の確認を済ませた固定の1枚をボタンで表示する実装で、別のPDFの自動読取り・自動更新はまだできません。線や数値の間では短い直線で近似した境界です。色は5段階の緑で、原図の黒い線を保持する乗算合成を使います。画面とPNGは同じ領域・区分・配色・凡例を使用します。資料が不一致・欠落・不正な場合は着色を停止します。原図の等風速線の説明は[気象庁「実況資料の解説」](https://www.jma.go.jp/jma/kishou/know/expert/pdf/kaisetsu_jikkyo.pdf)を参照してください。

強風軸候補は、強風帯を横切る方向で最も強い風速区分の中心を結ぶ線です。北西側の2本と、日本付近から東へ延びる1本を分けて表示します。等高度線の密集だけで作っていた旧候補は使用しません。気象庁の解析や予報ではありません。

原図PDFから連続した高度線を抽出し、海岸線・数値の字形・矢羽根・破線を除外した33本をcontours.jsonへ収録しています。このPDFの線の太さと形を確認して抽出したもので、任意のPDFや別の日時へ無検証で適用できる抽出器ではありません。曲線は原画像の画素座標です。source・imageのSHA-256、観測時刻、2048×2993の寸法がchart.jsonと一致しない場合は解析案を出しません。元の黒い図は変更しません。

図の経線の交点を円弧状の緯線の中心として使い、曲線を角度と中心からの距離へ変換します。緯線自体の湾曲をトラフと取り違えないための変換で、緯度・経度や実距離を数値出力するものではありません。

- 500hPaトラフ候補：閉曲線と角度幅0.48rad以下の短い線を除き、0.012radごとに南側の交点を標本化します。左右約0.096radより7画素以上南へ張り出す点を抽出します。同じ線の近接ピークの二重採用を避け、角度差0.18rad・距離差210画素以内の点を、異なる3本以上の曲線かつ90画素以上の南北幅がある場合だけ結びます。閉じた低気圧中心や短波のトラフを網羅しません。
- 300hPa強風軸候補：この1枚の等風速線と矢羽根に沿って確認した3つの流れの経路をjet-guides.jsonに収録しています。経路の点ごとに隣接点から流れの向きを求め、直交する断面（経路から片側90〜100画素以内）を各風速領域と交差させます。幅4画素以上ある最も高い20kt区分を選び、その断面内の区間の中点を採用します。同じ区分が分かれている場合は経路に近い中点を選びます。中点を接線が連続する3次のBézier曲線で結び、下流側の端に赤い矢印を付けます。矢印は風向、赤い線は強風帯の中心を示し、風速の数値を追加推定しません。

流れの経路・分岐・矢印方向の選択はこの1枚について確認したものです。中心点の位置は風速領域から計算しますが、別の日の流れや分岐を自動で発見する機能はまだありません。20kt幅の領域内で正確な風速極大位置は一意に決まらないため、最も強い区分の中心を強風軸の近似とします。断面間の形は滑らかな補間で、格子風・鉛直断面から三次元のジェット軸を決める解析とは異なります。風速の根拠がない経路は線を出さず、元の経路をそのまま軸として表示しません。強風軸の資料も原図・画像のSHA-256、観測時刻、寸法、300hPaと照合します。画面とPNGは同じ曲線・赤色・矢印を使用します。

トラフ用の角度を調べる範囲は−1.05〜0.5radです。抽出不足・曲がりが不明瞭な場所は候補を出しません。候補がないことはトラフや強風がない証明ではありません。資料が欠けた場合は原図の閲覧・手描き・拡大縮小を残し、解析ボタンを停止します。検証は合成した谷・風速帯と、この1枚への重ね合わせに限定しており、他日・他図の気象解析精度は未検証です。

## 図と出典

原図：[気象庁 AUPQ35 00UTC PDF](https://www.jma.go.jp/bosai/numericmap/data/nwpmap/aupq35_00.pdf)。初版は2026年10月2日00UTC（09:00 JST）の図を取得し、全ページを縦横比を保った2048×2993 PNGへ画像化しています。上段は300hPa、下段は500hPaです。取得した1枚を表示し、自動更新は行いません。原図URLの内容は後日更新されるため、画面の図の日時を確認してください。

利用条件：[気象庁ホームページの利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html)（公共データ利用規約第1.0版）。出典・画像化を画面に表示し、利用者による着色を気象庁の解析として扱いません。原図の気象要素の値は変更しません。取得PDFは公開リポジトリに含めず、レビューした画像と抽出線だけを配信します。図のハッシュ・寸法・取得日時はchart.jsonと公開許可一覧に固定しています。

解析案と手描きは図を読み取る補助です。PCのPDFを開く機能、自動更新、過去分の保存はまだありません。最新の状況は気象庁の原資料で確認してください。

## 開発・公開

`python3 -m http.server 8765 --bind 127.0.0.1` でローカル表示できます。ブラウザ側に依存ライブラリ・第三者CDN・解析タグはありません。

公開するファイルはrelease-allowlist.jsonの完全一致一覧で管理します。変更後は`python3 -B scripts/update_manifest.py`、`node scripts/test_analysis.js`、`python3 -B scripts/privacy_gate.py`、`python3 -B scripts/test_privacy_gate.py`、`python3 -B scripts/test_pages_release.py`を実行してください。Gitの投稿者は許可した公開用の名前とGitHub非公開用メールだけを使います。画像を更新するときは原図の日時、権利、目視確認、メタデータ除去、許可する画像ハッシュを再確認してください。

mainとrelease用ブランチで全Git objectを検査し、検査後の同一commitから許可ファイルだけを梱包します。Pages配備はmainだけです。配備される画像・コードはローカルと同じバイトです。公開時刻や通信ログと利用者の着色内容は別です。詳細はSECURITY.mdを参照してください。
